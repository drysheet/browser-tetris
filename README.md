# browser-tetris

A complete Tetris game built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` from the repository root in a desktop browser.

## Controls

- `Start` / `Pause` button to control play
- `Restart` button to begin a new run
- `←` and `→` to move the active piece
- `↑` or `Space` to rotate
- `↓` for soft drop
